# C Programming Foundations for Embedded Systems

This repository contains my daily practice codes and implementations as part of my journey toward becoming an **Embedded Software Engineer**. 

## 📌 Topics Covered

### Day 1: Basics & Data Types
- Basic C syntax, header files, and `main()` function
- Variables, Data Types (`int`, `float`, `char`)
- Input/Output operations using `printf` and `scanf`
- Arithmetic operations & Type Casting `(float)` for exact precision

### Day 2: Decision Making & Logic
- Conditional statements (`if`, `else`, `else if`)
- Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- Even/Odd logic using Modulo `%` operator
- Finding the largest among multiple numbers using Logical AND (`&&`)
